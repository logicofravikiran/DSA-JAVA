
#include<iostream>   // For input and output operations
#include<omp.h>      // OpenMP library for parallel programming

using namespace std;


int minval(int arr[], int n){

    int minval = arr[0];   // Assume first element is minimum

    // Parallel loop with reduction
    // Each thread maintains its own local minval
    #pragma omp parallel for reduction(min : minval)

    for(int i = 0; i < n; i++){

        // Compare current element with minimum
        if(arr[i] < minval)

            // Update minimum
            minval = arr[i];
    }

    // Return final minimum value
    return minval;
}


int maxval(int arr[], int n){

    int maxval = arr[0];   // Assume first element is maximum

    // Parallel loop with reduction
    #pragma omp parallel for reduction(max : maxval)

    for(int i = 0; i < n; i++){

        // Compare current element with maximum
        if(arr[i] > maxval)

            // Update maximum
            maxval = arr[i];
    }

    // Return final maximum value
    return maxval;
}


int sum(int arr[], int n){

    int sum = 0;   // Initialize summation variable

    // Parallel loop with addition reduction
    #pragma omp parallel for reduction(+ : sum)

    for(int i = 0; i < n; i++){

        // Add array element
        sum += arr[i];
    }

    // Return total sum
    return sum;
}


double average(int arr[], int n){

    // Convert to double for decimal result
    return (double)sum(arr, n) / n;
}

/*
==========================================================
                THEORY OF OPENMP REDUCTION
==========================================================

1) WHAT IS REDUCTION?
----------------------------------------------------------

Reduction is an OpenMP technique used to safely combine
results from multiple threads into a single variable.

Example:
- Sum
- Minimum
- Maximum
- Multiplication

Without reduction:
Multiple threads updating same variable can cause
RACE CONDITION.


==========================================================
2) RACE CONDITION
==========================================================

Race condition occurs when multiple threads access
and modify shared data simultaneously.

Example:

sum += arr[i];

If many threads execute this together,
incorrect results may occur.

Solution:
Use reduction clause.


==========================================================
3) OPENMP REDUCTION SYNTAX
==========================================================

#pragma omp parallel for reduction(operator : variable)

Example:

#pragma omp parallel for reduction(+ : sum)

Operators supported:
+   Addition
*   Multiplication
min Minimum
max Maximum


==========================================================
4) HOW REDUCTION WORKS
==========================================================

Suppose array:

1 2 3 4

Using 2 threads:

Thread 1:
1 + 2 = 3

Thread 2:
3 + 4 = 7

Final:
3 + 7 = 10

OpenMP automatically combines results.


==========================================================
5) WHAT IS OPENMP?
==========================================================

OpenMP (Open Multi-Processing) is an API for
parallel programming in C/C++.

Used for:
- Multithreading
- Parallel loops
- Faster execution

Header File:
#include <omp.h>


==========================================================
6) IMPORTANT OPENMP DIRECTIVES
==========================================================

a) #pragma omp parallel
Creates parallel threads.

b) #pragma omp parallel for
Executes loop iterations in parallel.

c) reduction()
Safely combines thread results.


==========================================================
7) ADVANTAGES OF REDUCTION
==========================================================

- Faster computation
- Avoids race conditions
- Efficient parallel execution
- Better CPU utilization


==========================================================
8) TIME COMPLEXITY
==========================================================

Maximum Search:
O(n)

O(n)

Average:
O(n)
